# Goinfi Labs — Project Context & Architecture

## Overview
**Goinfi Labs** is the specialized digital engineering, custom software, web application, and mobile product development laboratory operated under the ecosystem of `goinfi.biz`.

## Official Brand & Positioning
- **Brand Name:** Goinfi Labs (formerly Goinfi IT)
- **Parent Ecosystem:** Goinfi (`https://goinfi.biz`)
- **Domain:** `https://labs.goinfi.biz`
- **Primary Mission:** Client acquisition for high-value Web Development, Custom Software Engineering, and Mobile App Development projects.
- **Lead WhatsApp:** `+977 9715100200`
- **Email:** `support@goinfi.biz`
- **Headquarters:** Kathmandu & Pokhara, Nepal

## The 3 Core Pillars
1. **Web Page & Web App Development:**
   - Full-stack Next.js, React, modern corporate landing pages, high-converting portals, eSewa/Khalti/Stripe checkouts, SEO-optimized (95+ Core Web Vitals).
2. **Custom Software & Enterprise Systems:**
   - Tailored business software, ERP/CRM systems, billing engines, workflow automation, Node.js/Python backends, PostgreSQL/Redis architectures, high-concurrency REST/GraphQL APIs.
3. **Mobile App Development (iOS & Android):**
   - Native cross-platform applications built with Flutter & React Native, in-app digital wallets, OTP verification, offline syncing, App Store & Google Play publishing.

## Design & Aesthetics
- **Theme:** Invoidea-inspired dark cyber aesthetic with obsidian background (`#050811`), glowing dynamic radial mesh orbs (electric blue `#0070f3`, cyan `#06b6d4`, indigo `#6366f1`), interactive HTML5 particle canvas, and glassmorphic cards.
