# Goinfi — Official Agency & Cloud Web Platform

Welcome to the official agency web platform for **Goinfi** (`goinfi.biz`).

## 🚀 Live Local Preview
Open your web browser and visit:
```
http://localhost:4000
```

## 🛠️ Features Included:
1. **Hero Section:** High-converting headline, trust badges, and primary call-to-actions.
2. **Interactive Cost & Timeline Calculator:** Clients can customize their requirements (Corporate / E-Commerce / App) and calculate live pricing in रु. (NPR).
3. **Instant WhatsApp Quote Dispatch:** Clients can click "Lock This Quote on WhatsApp" which auto-formats a detailed quote message directly into WhatsApp chat.
4. **Transparent Packages:**
   - Starter Corporate (रु. १४,९९९)
   - E-Commerce Pro with eSewa/Khalti (रु. ३४,९९९)
   - Custom Mobile Apps & Cloud (रु. ६९,९९९+)
   - Annual NVMe Cloud Hosting & Care (रु. ४,९९९/वर्ष)
5. **Portfolio Showcase:** Filterable by E-commerce, Corporate, and Mobile Apps.
6. **Managed Cloud Hosting:** Showcase for recurring hosting revenue.
7. **Interactive FAQ Accordion:** Explaining timeline, payments, admin access, and renewals in clear Nepali & English.
8. **Floating WhatsApp Chat Widget:** Constant conversion magnet at bottom-right.

## 📱 How to Change WhatsApp Number & Email:
Inside `index.html`:
- Replace `9779800000000` with your actual WhatsApp phone number (e.g. `97798XXXXXXXX`).
- Replace `support@goinfi.biz` with your preferred support email.

## 🌐 How to Deploy to Production (goinfi.biz):
- Since this is a pure static high-performance website (HTML/CSS/JS), you can simply upload `index.html` directly to:
  - Your cPanel `public_html` directory, OR
  - Hostinger / Vercel / Netlify / Cloudflare Pages with zero build steps!
